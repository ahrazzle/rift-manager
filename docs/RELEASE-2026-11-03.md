## Contributor verification

Use Node.js 22 or newer, run `npm ci`, `npm test`, then `npm run build`.
Production uses `lck-manager-save-v1`; staging uses a separate save key. Map
presentation preferences have their own storage key and do not change match
results or game-save format. Never copy browser saves or credentials into an issue.
